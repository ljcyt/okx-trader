# Web 面板与安全模型

启动：`python -m okx_trader run-loop --serve`（循环主线程 + 面板守护线程，单一 SQLite 写者）；
循环跑在别的进程时用 `python -m okx_trader serve`（只读，控制端点 409）。

## 页签

| 页签 | 内容 |
|---|---|
| 总览 | 环境徽章、权益/回撤/持仓磁贴、熔断横幅、数据健康条、只读风控限额 |
| 权益 | 内联 SVG 曲线：权益线 + 高水位虚线 + 回撤红色填充带 |
| 决策历史 | 分页表（状态/标的筛选）；点开是六步漏斗 |
| 六步漏斗 | 因子快照（含逐字 LLM 输入）→ 分析师 → 裁判矩阵+聚合算式 → 胜出 → 硬风控（规则码+大白话注解）→ 执行；页脚 llm_calls |
| 交易 | 已平/未平、R 倍数、按标的与按分析师盈亏 |
| 事件 | data_degraded / circuit_breaker / stop_reattached / env_switch / login |

## 安全模型（设计约束，不是疏漏）

- 默认只绑 `127.0.0.1`；`WEB_HOST="0.0.0.0"` 必须同时设置 `WEB_PASSWORD`，否则拒绝启动
- 局域网是**明文 HTTP**：密码每次登录过一次网线，cookie 每个请求都过。
  单人内网工具可接受；公网暴露请自架 TLS 反代并自担风险
- 会话只存内存，重启即登出；同一 IP 5 次失败锁 60 秒
- **刻意不提供**下单/撤单/切环境/改风控参数的端点——cookie 被盗的影响半径
  是"能看、能暂停"，不是"能交易"
- `/api/state` 的限额字段是手写白名单；密钥永远不会出现在任何响应里
